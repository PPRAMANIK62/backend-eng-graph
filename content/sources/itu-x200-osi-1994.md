## Summary

The OSI reference model, 1994 edition, free from the ITU (the PDF is
linked from this page). It defines seven layers and gives each a
number, which is where "layer 4" and "layer 7" come from.

## Key claims

- Same text as the ISO standard. "identical text is also published as ISO/IEC International Standard 7498-1." (Foreword)
- Seven numbered layers, from Application (7) down to Physical (1). "The Reference Model contains seven layers:" then "the Application Layer (layer 7);" ... "the Transport Layer (layer 4);" "the Network Layer (layer 3);" "the Data Link Layer (layer 2); and" "the Physical Layer (layer 1)." (6.1.2)
- Transport protocols run end to end, between end systems only. "transport-protocols operate only between OSI end open systems." (7.4.2.3)
- The transport layer doesn't deal with routing. "The Transport Layer is relieved of any concern with routing and relaying" (7.4.2.4)

## My notes

- The Internet's four-layer model (RFC 1122) has no presentation or
  session layer; people still use OSI's numbers (L2, L3, L4, L7) when
  talking about devices. See `network-layers`.
