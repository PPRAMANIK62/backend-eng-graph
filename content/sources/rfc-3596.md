## Summary

Defines the AAAA record (type 28), which holds one IPv6 address, and
the IP6.ARPA domain for reverse lookups of IPv6 addresses.

## Key claims

- AAAA holds a single IPv6 address. "The AAAA resource record type is a record specific to the Internet class that stores a single IPv6 address." (2.1)
- Its type number is 28. "The IANA assigned value of the type is 28 (decimal)." (2.1)
- The data is the 128-bit address in network byte order. "A 128 bit IPv6 address is encoded in the data portion of an AAAA resource record in network byte order (high-order byte first)." (2.2)
- IPv6 reverse lookups use IP6.ARPA. (2.5)
