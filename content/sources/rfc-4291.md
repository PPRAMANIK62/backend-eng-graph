## Summary

The IPv6 addressing standard: 128-bit addresses, the three address types,
the text format, prefixes, and the layout of global unicast and
link-local addresses. Updated by 6 RFCs, including RFC 5952 (the
recommended text form) and RFC 7136 (rfc-editor.org info page).

## Key claims

- IPv6 addresses are 128 bits and name interfaces. "IPv6 addresses are 128-bit identifiers for interfaces and sets of interfaces" (2)
- Three types: unicast, anycast, multicast. Anycast goes to "the \"nearest\" one, according to the routing protocols' measure of distance" (2)
- No broadcast in IPv6. "There are no broadcast addresses in IPv6, their function being superseded by multicast addresses." (2)
- Addresses belong to interfaces, not nodes. "IPv6 addresses of all types are assigned to interfaces, not nodes." (2.1)
- Every interface has a link-local address, and may have many more. "All interfaces are required to have at least one Link-Local unicast address" (2.1)
- Written as eight 16-bit hex groups. "The preferred form is x:x:x:x:x:x:x:x, where the 'x's are one to four hexadecimal digits of the eight 16-bit pieces of the address." (2.2)
- "::" stands for a run of zero groups, once per address. "The \"::\" can only appear once in an address." (2.2)
- Examples: ::1 is loopback, :: is unspecified, 2001:DB8::8:800:200C:417A. (2.2)
- Prefixes use CIDR-style notation. "ipv6-address/prefix-length" (2.3)
- Type by leading bits: ::1/128 loopback, FF00::/8 multicast, FE80::/10 link-local, everything else global unicast. (2.4, table)
- Anycast addresses look exactly like unicast. "Anycast addresses are taken from the unicast address spaces (of any scope) and are not syntactically distinguishable from unicast addresses." (2.4)
- Global unicast = global routing prefix + subnet ID + interface ID. (2.5.4, diagram)
- The interface ID is 64 bits for global unicast (other than addresses starting 000). "All Global Unicast addresses other than those that start with binary 000 have a 64-bit interface ID field (i.e., n + m = 64)" (2.5.4)
- An IPv4-mapped IPv6 address is 80 zero bits, 16 one bits (FFFF), then the IPv4 address; it represents an IPv4 node as an IPv6 address. "This address type is used to represent the addresses of IPv4 nodes as IPv6 addresses." (2.5.5.2)
- Link-local addresses stay on the link. "Routers must not forward any packets with Link-Local source or destination addresses to other links." (2.5.6)
- Nodes shouldn't assume structure beyond the subnet boundary. "nodes should not make any assumptions about the structure of an IPv6 address." (2.5)

Added 2026-09-28 (audit) for `ip-addressing`:

- The routing prefix is assigned to a site; the subnet ID names a link inside it. "the global routing prefix is a (typically hierarchically- structured) value assigned to a site (a cluster of subnets/links), the subnet ID is an identifier of a link within the site" (2.5.4)

Added 2026-09-28 (audit) for `anycast`:

- Nodes holding an anycast address must be told it's anycast. "the nodes to which the address is assigned must be explicitly configured to know that it is an anycast address." (2.6)
