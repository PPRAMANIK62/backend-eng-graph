## Summary

IPv6's replacement for ARP (and more): address resolution, router
discovery, redirects and neighbor unreachability detection, all as ICMPv6
messages. Updated by 12 later RFCs (rfc-editor.org info page).

## Key claims

- ND combines three IPv4 mechanisms. "The IPv6 Neighbor Discovery protocol corresponds to a combination of the IPv4 protocols Address Resolution Protocol [ARP], ICMP Router Discovery [RDISC], and ICMP Redirect [ICMPv4]." (3.1)
- ND relies on link-layer multicast. "because ND uses link-layer multicast for some of its services" (1)
- Address resolution defined. "Address resolution is the process through which a node determines the link-layer address of a neighbor given only its IP address." (7.2)
- Unlike ARP, it notices half-broken links. "Unlike ARP, Neighbor Discovery detects half-link failures (using Neighbor Unreachability Detection)" (3.1)
- It runs at the ICMP layer, so it's more media-independent than ARP. "Placing address resolution at the ICMP layer makes the protocol more media-independent than ARP" (3.1)

Added (audit) for `ethernet-and-arp`:

- Address resolution uses a multicast Neighbor Solicitation, not a broadcast, and a unicast reply. "Neighbor Solicitation messages are multicast to the solicited-node multicast address of the target address." (3, Address resolution)
