## Summary

The OpenTofu project's FAQ, read when OpenTofu 1.12 was current: why
the Terraform fork exists and how compatible it is.

## Key claims

- OpenTofu is a fork created after HashiCorp moved Terraform from an open-source licence to the BUSL. "OpenTofu is a Terraform fork, created as an initiative of Gruntwork, Spacelift, Harness, Env0, Scalr, and others, in response to HashiCorp's switch from an open-source license to the BUSL." (Why was OpenTofu created?)
- It was given to the Linux Foundation. "This risk is minimized by giving OpenTofu to the Linux Foundation" (Companies)
- State compatibility stops at Terraform 1.5.x. "OpenTofu will work with existing state files up to those created with Terraform versions 1.5.x." (existing state file)
- Same providers, separate registry. "OpenTofu works with the current Terraform providers, but it uses a separate registry." (providers)
