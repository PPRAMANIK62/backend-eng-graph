## Summary

The original ICMP for IPv4. Short messages that routers and hosts send
back to a packet's source to report a problem (destination unreachable,
time exceeded) or to answer a query (echo, used by ping). Carried inside
IP with protocol number 1.

## Key claims

- ICMP rides in IP but is part of IP. "ICMP, uses the basic support of IP as if it were a higher level protocol, however, ICMP is actually an integral part of IP, and must be implemented by every IP module." (Introduction)
- It reports problems; it doesn't make IP reliable. "The purpose of these control messages is to provide feedback about problems in the communication environment, not to make IP reliable." (Introduction)
- No guarantee a message comes back. "There are still no guarantees that a datagram will be delivered or a control message will be returned." (Introduction)
- No ICMP about ICMP, and only about fragment zero. "To avoid the infinite regress of messages about messages etc., no ICMP messages are sent about ICMP messages." (Introduction)
- Protocol number. "ICMP = 1" (Message Formats, Protocol)
- Destination Unreachable (type 3) codes: "0 = net unreachable; 1 = host unreachable; 2 = protocol unreachable; 3 = port unreachable; 4 = fragmentation needed and DF set; 5 = source route failed." (Destination Unreachable Message)
- Error messages carry the original IP header plus the first 64 bits of its data, so the host can find the socket (ports sit there). "If a higher level protocol uses port numbers, they are assumed to be in the first 64 data bits of the original datagram's data." (Destination Unreachable Message)
- A host sends port unreachable when no process listens. "the destination host may send a destination unreachable message to the source host." (Destination Unreachable Message, Description)
- Too big with DF set: the router drops it and may say so. "Another case is when a datagram must be fragmented to be forwarded by a gateway yet the Don't Fragment flag is on. In this case the gateway must discard the datagram and may return a destination unreachable message." (Destination Unreachable Message, Description)
- Time Exceeded (type 11), code 0 when TTL reaches zero. "If the gateway processing a datagram finds the time to live field is zero it must discard the datagram. The gateway may also notify the source host via the time exceeded message." (Time Exceeded Message)
- Echo is type 8, echo reply type 0; the reply returns the data, identifier and sequence number. "The data received in the echo message must be returned in the echo reply message." (Echo or Echo Reply Message)
- Other types in the 1981 summary: 4 Source Quench, 5 Redirect, 12 Parameter Problem, 13/14 Timestamp. (Summary of Message Types)

Added 2026-09-28 (audit) for `icmp`:

- The reply swaps the addresses and changes the type. "To form an echo reply message, the source and destination addresses are simply reversed, the type code changed to 0, and the checksum recomputed." (Echo or Echo Reply Message)
- The sender matches replies by identifier and sequence number. "The identifier and sequence number may be used by the echo sender to aid in matching the replies with the echo requests." (Echo or Echo Reply Message)
