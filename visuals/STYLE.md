# How figures are drawn

Written 2026-09-28. Every figure in an article is an SVG file in
`content/nodes/phase-N/img/`, named `<node-id>-<what-it-shows>.svg`.
Diagrams are written by hand. Charts of experiment data are generated by a
script from the raw data, so every number can be traced back to a run.
`visuals/reference.svg` shows the style below in use.

## Numbers

A number goes in a figure only if it's in a source note or an experiment.
If it isn't, leave the number out and draw the shape. A figure that would
be nothing but unverified numbers doesn't get drawn.

## In the article

The `<!-- VISUAL: ... -->` comment is replaced by the image and a caption:

```markdown
![Alt text that says what the figure shows, in one or two sentences.](img/fsync-layers.svg)

*The five places a write can wait. Adapted from Jeff Moyer, "Ensuring data reaches disk" (LWN, 2011).*
```

Captions say "Adapted from <author>, <title>" when the idea or layout came
from a source (that source must be in Further reading), and nothing when
it's our own drawing. Data charts say which experiment they came from.

## The SVG

- `viewBox="0 0 720 H"` with `width="720"`, H as small as the content
  allows. No fixed background: the page's background shows through.
- Colours come from CSS classes in an inline `<style>`, with a
  `prefers-color-scheme: dark` block, never from hard-coded fills on
  shapes. Copy the `<style>` block from `visuals/reference.svg` as is.
- Text: `system-ui` sans, 14px for labels, 12px for notes. Code, flags and
  byte values in `ui-monospace`. Sentence case. No text smaller than 12px.
- Boxes: 1.5px strokes, 6px rounded corners. Arrows: 1.5px, with the
  shared `#arrow` marker.
- Colour means one thing everywhere (always with a text label too, never
  colour alone):

| Class | Light | Dark | Means |
|---|---|---|---|
| `ink` | `#0b0b0b` | `#ffffff` | main text |
| `ink2` | `#52514e` | `#c3c2b7` | secondary text, notes |
| `box` | fill `#f0efec`, stroke `#8a8984` | fill `#2a2a28`, stroke `#8a8984` | a neutral box |
| `focus` | `#2a78d6` | `#3987e5` | the thing the figure is about, new data |
| `lost` | `#eb6834` | `#d95926` | lost, torn, wrong, a crash |
| `safe` | `#1baf7a` | `#199e70` | durable, correct, survives |
| `old` | `#b8b7b2` | `#5c5b57` | old or stale data, garbage |

- At most three colours besides neutrals in one figure.
- Render before using it: `rsvg-convert -w 1440 file.svg -o /tmp/x.png`
  (and once with a dark background: `-b '#1a1a19'` after swapping in the
  dark values, or just check the light one if the classes are right).
  Look for overlapping text, clipped labels and arrows that miss.
