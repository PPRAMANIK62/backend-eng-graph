## Summary

A two-page standard for putting IP packets inside Ethernet frames. It's
where the 1500-byte MTU of Ethernet comes from as far as IP is concerned.

## Key claims

- The largest IP packet in one Ethernet frame is 1500 bytes. "thus the maximum length of an IP datagram sent over an Ethernet is 1500 octets." (Frame Format)
- The minimum data field is 46 bytes, padded if needed. "The minimum length of the data field of a packet sent over an Ethernet is 46 octets." (Frame Format)
- Hosts that can't take full-size packets should say so with the TCP MSS option. "it should take steps to discourage others from sending them, such as using the TCP Maximum Segment Size option" (Frame Format)
