## Summary

The FQ-CoDel spec (Experimental). FQ-CoDel hashes packets into many
per-flow queues, serves them round robin, gives flows that don't build
a queue priority, and runs CoDel on each queue. It was developed in
Linux, where it ships as the `fq_codel` qdisc, and the authors include
its Linux implementer.

## Key claims

- Status: Experimental. (header)
- What it is: a scheduler plus AQM against bufferbloat. "This memo presents the FQ-CoDel hybrid packet scheduler and Active Queue Management (AQM) algorithm, a powerful tool for fighting bufferbloat and reducing latency." (Abstract)
- It protects low-rate traffic from bulk flows. "It provides isolation for low-rate traffic such as DNS, web, and videoconferencing traffic." (Abstract)
- Built from Deficit Round Robin with CoDel on each queue. "It is based on a modified Deficit Round Robin (DRR) queue scheduler [DRR] [DRRPP] with the CoDel AQM [RFC8289] algorithm operating on each queue." (1)
- Flows are found by hashing the 5-tuple; by default into 1024 queues. "By default, 1024 queues are created." (1.3)
- New flows that haven't built a queue are served first. "flows that build a queue are treated differently from flows that do not." (1.3)
- CoDel defaults in FQ-CoDel: target 5 ms, interval 100 ms. "The default target value is 5 ms" and "The default interval value is 100 ms." (5.2.2 Target, 5.2.1 Interval)
- In Linux since 3.5 (2012-07-21), and the default qdisc in some distributions. "has been shipped as part of the Linux kernel since version 3.5 (released on the 21st of July, 2012)" and "(as of this writing, at least OpenWRT, Arch Linux, and Fedora)" (7)
- Results versus plain FIFO. "All data resulting from these trials have shown FQ-CoDel to be a massive improvement over the previous default FIFO queue, and people are encouraged to turn it on." (7)
- Cake is the bufferbloat community's follow-on. "One such effort has been undertaken by the bufferbloat community in the form of the Cake queue management scheme" (7)
