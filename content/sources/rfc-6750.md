## Summary

How a client presents an OAuth access token (2012): the `Authorization:
Bearer` header, and why a bearer token is like cash.

## Key claims

- Whoever holds a bearer token can use it; no proof of a key needed. "A security token with the property that any party in possession of the token (a \"bearer\") can use the token in any way that any other party in possession of it can." (1.2)
- The header form. "Authorization: Bearer mF_9.B5f-4.1JqM" (2.1, example)
- Don't put bearer tokens in URLs. "Bearer tokens SHOULD NOT be passed in page URLs (for example, as query string parameters)." (5.3)
