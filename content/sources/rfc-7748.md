## Summary

Defines Curve25519 and Curve448 and the X25519 and X448 functions for
Diffie-Hellman key agreement (2016). Section 6 walks through a key
exchange between Alice and Bob.

## Key claims

- X25519 is used for elliptic-curve Diffie-Hellman. "The X25519 function can be used in an Elliptic Curve Diffie-Hellman (ECDH) protocol as follows:" (6.1)
- Each side picks 32 random bytes as its private key. "Alice generates 32 random bytes in a[0] to a[31] and transmits K_A = X25519(a, 9) to Bob" (6.1)
- Both sides end up with the same shared secret. "Both now share K = X25519(a, X25519(b, 9)) = X25519(b, X25519(a, 9)) as a shared secret." (6.1)
- The shared secret goes through a key-derivation function to make a symmetric key. "Alice and Bob can then use a key-derivation function that includes K, K_A, and K_B to derive a symmetric key." (6.1)
- A large quantum computer would break curve25519. "Large quantum computers, if ever created, will break both curve25519 and curve448" (7)
