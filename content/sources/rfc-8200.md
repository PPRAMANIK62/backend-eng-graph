## Summary

The IPv6 standard (STD 86), obsoleting RFC 2460. Used here for the header
layout, the Hop Limit field, and the minimum header sizes. Updated by
RFC 9673 (per rfc-editor.org info page).

## Key claims

- The IPv6 header carries a 128-bit source and destination address, a Next Header field and a Hop Limit. (3, header diagram)
- Hop Limit works like IPv4's TTL: each forwarder decrements it and drops the packet at zero. "Decremented by 1 by each node that forwards the packet." (3, Hop Limit)
- Minimum header sizes: IPv4 20 octets, TCP 20 octets, IPv6 20 more than IPv4. "minus 40 octets (20 octets for the minimum-length IPv4 header and 20 octets for the minimum-length TCP header)" (8.3)
- "the minimum-length IPv6 header (i.e., an IPv6 header with no extension headers) is 20 octets longer than a minimum-length IPv4 header." (8.3)
