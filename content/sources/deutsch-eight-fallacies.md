## Summary

The canonical one-screen list, on James Gosling's site, attributed to Peter
Deutsch. Eight assumptions people make when they first build a distributed
application, and a one-line warning that all of them turn out false.

## Key claims

- Everyone makes these assumptions at first, and they cause trouble. "Essentially everyone, when they first build a distributed application, makes the following eight assumptions." (intro)
- They all fail eventually. "All prove to be false in the long run and all cause big trouble and painful learning experiences." (intro)
- The list: the network is reliable; latency is zero; bandwidth is infinite; the network is secure; topology doesn't change; there is one administrator; transport cost is zero; the network is homogeneous. "The network is homogeneous" (list, item 8)
