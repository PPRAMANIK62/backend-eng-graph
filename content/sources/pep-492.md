## Summary

The Python Enhancement Proposal that added `async def` and `await` in
Python 3.5 (2015). It makes coroutines their own kind of object, separate
from generators, assumes an event loop like asyncio's schedules them,
and explains why a separate `async` keyword is needed.

## Key claims

- Goal: make async code as close to synchronous code as possible. "make it as close to synchronous programming as possible." (Abstract)
- It assumes an event loop schedules the coroutines. "This PEP assumes that the asynchronous tasks are scheduled and coordinated by an Event Loop similar to that of stdlib module asyncio.events.AbstractEventLoop." (Abstract)
- Before this, Python coroutines were generators (PEP 342, PEP 380), easy to confuse with ordinary generators. "It is easy to confuse coroutines with regular generators, since they share the same syntax" (Rationale and Goals)
- Calling a coroutine function returns a coroutine object, not a result. "Regular generators, when called, return a generator object; similarly, coroutines return a coroutine object." (New Coroutine Declaration Syntax)
- A coroutine that is never awaited triggers a warning when collected. "When a native coroutine is garbage collected, a RuntimeWarning is raised if it was never awaited on" (New Coroutine Declaration Syntax)
- await suspends the coroutine until the awaitable completes. "await, similarly to yield from, suspends execution of read_data coroutine until db.fetch awaitable completes and returns the result data." (Await Expression)
- Every await chain bottoms out in a yield to the event loop. "every await is suspended by a yield somewhere down the chain of await calls" (Await Expression)
- async/await existed in other languages first: C#, a proposal for ECMAScript 7, Hack, Dart, Scala, C++ proposals. "C# has it since long time ago" (Why "async" and "await" keywords)
- Without the async keyword, removing the last await from a function would silently turn it into a normal function and break its callers. "If useful() function is refactored and someone removes all await expressions from it, it would become a regular python function, and all code that depends on it, including important() would be broken." (Importance of "async" keyword)
