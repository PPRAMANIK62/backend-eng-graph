## Summary

A short best current practice from 2026. Any new protocol that uses TLS
must default to TLS 1.3. It updates RFC 9325, notes that TLS 1.2 won't
get post-quantum support, and lists the weaknesses of TLS 1.2.

## Key claims

- New protocols must require TLS 1.3. "Therefore, new protocols that use TLS must require TLS 1.3." (Abstract)
- TLS 1.3 must be the default for any new protocol. "Any new protocol that uses TLS MUST specify TLS 1.3 as its default." (4)
- QUIC already requires TLS 1.3. "For example, QUIC [QUICTLS] requires TLS 1.3 and specifies that endpoints MUST terminate the connection if an older version is used." (4)
- The TLS working group is not adding to TLS 1.2, including post-quantum work. "It is important to note that the TLS Working Group is focusing its efforts on TLS 1.3 or later; TLS 1.2 will not be supported" (3)
- TLS 1.2 can be secure but is harder to configure. "TLS 1.2 can be configured securely; it is merely much more difficult to configure it securely as opposed to using its modern successor, TLS 1.3." (6)
- CBC suites in TLS 1.2 have a long record of attacks. "CBC cipher suites have been a source of vulnerabilities throughout the years." (6)
