## Summary

John Nagle's 1984 memo from Ford Aerospace's network. It names
congestion collapse and describes the "small-packet problem" and its
fix, now called Nagle's algorithm. Informational, not a standard.

## Key claims

- The memo doesn't set a standard. "this memo does not specify any standards." (opening)
- Typing one character at a time sends 41-byte packets for one byte of data. "the typical result is that 41 byte packets (one byte of data, 40 bytes of header) are transmitted for each byte of useful data." (The small-packet problem)
- That's a 4000% overhead. "This 4000% overhead is annoying but tolerable on lightly loaded networks." (The small-packet problem)
- The fix: don't send new segments while earlier data is unacknowledged. "The solution is to inhibit the sending of new TCP segments when new outgoing data arrives from the user if any previously transmitted data on the connection remains unacknowledged." (The solution to the small-packet problem)
- No timers. "This inhibition is to be unconditional; no timers, tests for size of data received, or other conditions are required." (same)
- On an idle connection the data goes out at once, so there's no deadlock. "In the first case, the idle connection, our scheme will result in a packet being sent whenever the user writes to the TCP connection." (same)
- Timer-based batching (200-500 ms) was the older approach, and no single timer suits every network. (The small-packet problem)
- Congestion collapse: once hosts retransmit into a full network, it settles into a stable degraded state. "This condition is stable." (Congestion collapse)

Added for `nagle-and-delayed-ack` audit:

- The source of the tiny packets is keyboard input. "When TCP is used for the transmission of single-character messages originating at a keyboard" (The small-packet problem)
- On busy networks the overhead adds to congestion. "On heavily loaded net- works, however, the congestion resulting from this overhead can result in lost datagrams and retransmissions" (The small-packet problem)
