## Summary

The 2022 spec for DNS over QUIC (DoQ): DNS messages on QUIC streams,
one query per stream, on UDP port 853. Privacy like DoT, latency closer
to classic UDP DNS, and meant for every hop, not only stub to
recursive.

## Key claims

- Same privacy as DoT, latency like UDP DNS. "DNS over QUIC (DoQ) has privacy properties similar to DNS over TLS (DoT) specified in RFC 7858, and latency characteristics similar to classic DNS over UDP." (Abstract)
- A general-purpose transport for all DNS hops. "This specification describes the use of DoQ as a general-purpose transport for DNS and includes the use of DoQ for stub to recursive, recursive to authoritative, and zone transfer scenarios." (Abstract)
- UDP port 853. "By default, a DNS server that supports DoQ MUST listen for and accept QUIC connections on the dedicated UDP port 853" (4.1.1)
- Negotiated with the ALPN token "doq". "DoQ support is indicated by selecting the Application-Layer Protocol Negotiation (ALPN) token \"doq\" in the crypto handshake." (4.1)
- One query per stream avoids head-of-line blocking. "Mapping of each DNS Query/Response transaction to a separate stream, to mitigate head-of-line blocking." (3.2)
- DoQ doesn't try to hide that it's DNS. "No attempt is made to evade potential blocking of DoQ traffic by middleboxes." (1)
- DoH over HTTP/3 also gets QUIC, but DoQ is lighter where there are no intermediaries. "DNS over HTTPS (DoH) [RFC8484] can be used with HTTP/3 to get some of the benefits of QUIC." (1)
